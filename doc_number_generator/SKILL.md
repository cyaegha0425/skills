# 文档编号生成器

## 功能
根据用户提供的文档信息，自动匹配ISO文件管理体系，生成符合规范的文件编号和命名。

## 核心规则

### 编号前缀（按文件类型）

| 层级 | 文件类型 | 编号前缀 | 说明 |
|------|----------|----------|------|
| 1阶 | 手册/方针 | HF-MGMT-xxx | 手册类文件 |
| 2阶 | 程序文件 | HF-PROC-xxx | 程序文件 |
| 3阶 | 作业指导书/SOP | HF-WI-xxx | 作业指导书 |
| 4阶 | 表单/记录 | HF-FRM-xxx | 表单记录 |
| 技术文件 | 设计图/BOM等 | HF-TECH-xxx | 技术设计文件 |
| 用户手册 | 说明书 | HF-UM-xxx | 用户手册、运维手册 |

> xxx = 3位序号，按**大类**分配

### 产品大类分类（UM系列）

| 编号 | 产品大类 | 具体型号示例 |
|------|----------|--------------|
| UM-001 | 智慧阀门 | 无三通双头阀、普通球阀 |
| UM-002 | 施肥机 | 易耘E3 |
| UM-003 | 土壤墒情检测仪 | - |
| UM-004 | 微型气象站 | - |
| UM-005 | 泵房控制器 | - |

### 文档命名格式

```
{前缀}-{产品编号}-{日期}-{版本号}-{具体型号}-{文档类型} V{版本号}.docx
```

**示例**：
```
HF-UM-001-20260511-001-无三通双头阀-使用说明书 V1.0.docx
```

| 部分 | 说明 |
|------|------|
| HF-UM | 前缀+类型 |
| 001 | 3位序号，对应**产品大类** |
| 20260511 | 日期 |
| 001 | 版本内序号 |
| 无三通双头阀 | **具体型号**（不是大类名） |
| 使用说明书 | 文档类型 |
| V1.0 | 版本号 |

## 使用流程

1. **判断文档类型** → 确定前缀（MGMT/PROC/WI/FRM/TECH/UM）
2. **判断产品大类** → 确定序号（001/002/003/004/005）
3. **生成编号** → 前缀+序号
4. **生成命名** → 按格式拼接完整文件名
5. **更新台账** → 将新记录追加到台账

## 铁律

**⚠️ 编号对大类，产品名写具体型号**
- 编号（001-005）对应产品**大类**，不是具体型号
- 文件命名中的产品名写**具体型号**
- 示例：双头阀 → 编号UM-001，命名写"无三通双头阀"

## 知识库路径

- 规则定义：`./知识库/ISO文档管理/编号规则.md`
- 编号台账：`./知识库/ISO文档管理/编号台账.md`
