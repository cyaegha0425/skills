# 文档编号生成器

## 功能
根据用户提供的文档名称或描述，自动匹配ISO文件管理体系，生成符合规范的文件编号。

## 使用方式
1. 用户提供文档名称或描述
2. AI读取 `../知识库/ISO文档管理/生成规则.md` 判断文档类型
3. 读取 `../知识库/ISO文档管理/编号台账.md` 查找该前缀系列最新编号
4. 生成新编号（+1）
5. 将新记录追加到台账

## 交互流程

### 正常流程
- 读取生成规则判断类型
- 读取台账确认最新编号
- 输出：`[编号] 文档名称`
- 更新台账

### 无法判断时
- 向用户确认文档类型
- 用户选择编号前缀后继续

## 示例

**用户输入**："智慧阀门出厂检验规范"

**AI处理**：
1. 关键词"检验规范"→ HF-WI-xxx（作业指导书）
2. 台账HF-WI系列暂无记录 → HF-WI-001
3. 输出：`HF-WI-001 智慧阀门出厂检验规范`
4. 更新台账
